<objective>
## Goal
Uma pessoa que nunca viu o OpenLuz baixa a beta, instala, abre e põe uma imagem no projetor seguindo uma página só, sem o
Felipe do lado. E fica escrito o que ainda trava esse caminho.

## Purpose
"Eu quero ver esse app open-source pronto, quero melhorar a vida das pessoas" (Felipe, 2026-11-14). A beta.2 está pública e
ele já mandou o link para amigos. Ele delegou a escolha do próximo passo ("Escolha e dá-lhe"); a comparação da Saída
avançada com o Resolume (07-03) fica esperando.

## Output
- `13-01-PRIMEIRA-VEZ.md`: o que acontece na primeira abertura com a pasta de dados vazia, passo a passo, com foto, e onde um novato trava.
- `PRIMEIROS-PASSOS.md` (português e inglês), ligado no README; README com o status em dia (0.3.0-beta.2).
- No mesmo arquivo de achados: opções de assinatura do instalador, com custo e o que cada uma pede.
- Nenhuma mudança no programa.
</objective>

## AC-1: Primeira vez medida
```gherkin
Given a beta.2 instalada e uma pasta de dados que nunca foi usada
When abro o programa e faço, com mouse e teclado reais, o caminho mais curto até uma imagem na saída (abrir, pôr um arquivo ou uma fonte numa casa, disparar, abrir a saída numa janela)
Then cada passo tem foto e o que aparece na tela, e fica anotado tudo o que um novato não teria como saber (diálogo que surge, pasta vazia, botão sem nome, aviso do Windows)
```

## AC-2: Página de primeiros passos que funciona
```gherkin
Given PRIMEIROS-PASSOS.md em português e inglês
When sigo só o que está escrito nela, a partir do link de download
Then chego a uma imagem na saída sem precisar de nada que não esteja na página; os nomes de botões e menus são os que aparecem no programa
```

## AC-3: README em dia
```gherkin
Given o README
When leio o status e a seção Baixar
Then eles falam da 0.3.0-beta.2, apontam para a página de releases e para os primeiros passos, e avisam do SmartScreen
```

## AC-4: Assinatura: opções na mesa
```gherkin
Given o instalador sem assinatura
When o plano fecha
Then há uma lista curta de caminhos (programa gratuito para código aberto, certificado pago, loja da Microsoft), com custo, prazo, o que o Felipe precisa fornecer e a minha recomendação; o que eu não consegui confirmar vem marcado
```

## AC-5: O programa não muda
```gherkin
Given o plano inteiro
When olho o git e os processos
Then só entraram documentos e o roteiro; nada em app/ ou main.js; os dados do OpenLuz instalado do Felipe não foram tocados; nada aberto
```
