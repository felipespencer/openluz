## AC-1: Ctrl+Z não atravessa a troca de composição
```gherkin
Given a composição A aberta e depois a B aberta
When se aperta Ctrl+Z (tecla real)
Then a grade continua sendo a da B ("Nada para desfazer") e o Ctrl+S não grava a A no arquivo da B
```

## AC-2: Apagar e sobrescrever pedem confirmação
```gherkin
Given uma composição salva na lista
When se clica no ✕ dela
Then aparece uma pergunta; Cancelar mantém o arquivo; OK tira o arquivo da pasta (vai para a Lixeira do Windows)
```
```gherkin
Given "Salvar como…" com o nome de outra composição que já existe
When se confirma o nome
Then aparece uma pergunta antes de gravar por cima; Cancelar não muda o arquivo
```
O mesmo vale para "Apagar preset" e para salvar preset com nome que já existe, na Saída avançada.

## AC-3: Nova e abrir outra avisam quando há mudança não salva
```gherkin
Given a grade com mudanças desde o último salvar/abrir
When se aperta Ctrl+N (ou "Nova", ou duplo clique em outra composição)
Then aparece uma pergunta; Cancelar mantém tudo; OK segue
```
```gherkin
Given a composição sem mudança desde o último salvar/abrir
When se aperta Ctrl+N
Then a composição nova vem direto, sem pergunta
```

## AC-4: O autosalvar cobre a grade vazia e não some com o nome começando em _
```gherkin
Given a grade sem clipes mas com algo mudado (opacidade de uma camada)
When o autosalvar roda
Then `_automatica.json` é gravado; com o programa recém-aberto e nada mexido, não é
```
```gherkin
Given um nome começando com _
When se salva a composição
Then o arquivo é gravado sem o _ da frente e aparece na lista
```

## AC-5: Gravação inteira ou nada; preferências não se apagam
```gherkin
Given salvar composição, preset ou preferências
When a gravação termina
Then o arquivo final é JSON válido e não sobra `.tmp` (escrita em arquivo temporário + troca de nome)
```
```gherkin
Given uma preferência qualquer gravada
When a aba Arquivos grava as dela (pasta, favoritos)
Then a outra preferência continua lá
```

## AC-6: F5 e o desfazer da Saída avançada
```gherkin
Given o programa instalado
When se aperta F5
Then nada recarrega (F5 só vale no programa de desenvolvimento)
```
```gherkin
Given mudanças feitas na Saída avançada e salvas
When um Ctrl+Z na grade desfaz essas mudanças
Then o aviso diz que desfez o que foi feito na Saída avançada e que Ctrl+Y refaz
```

```gherkin
When o selftest e todas as baterias rodam de novo
Then o resultado é igual (só o webcam-check reprova, como na linha de base)
```
