## AC-1: Um erro num quadro não congela o programa
```gherkin
Given Beat Snap em 16 batidas, BPM 60 e um clipe da Camada 1 na fila (clique real na miniatura)
When a Camada 1 é removida pelo menu Camada › Remover antes da batida, e a batida chega
Then os quadros continuam (mais de 40 em 2 s), não há exceção na página e a fila fica vazia
```
```gherkin
Given o programa rodando com um clipe no ar
When uma etapa do quadro lança uma exceção (injetada no teste em engine.render, uma vez e depois em todo quadro por 2 s)
Then o laço continua agendado, o erro vai para o registro uma vez por mensagem (não uma linha por quadro),
     aparece um aviso na tela uma vez, e quando a exceção para a imagem volta sozinha
```

## AC-2: A saída de um projetor não cai nem fica órfã ao mexer nas telas
```gherkin
Given duas telas de tamanhos diferentes com a janela de saída aberta e a Saída avançada aberta
When a primeira tela é duplicada e depois se dá Ctrl+Z (tecla real), e também Cancelar depois de duplicar
Then as duas janelas de saída continuam abertas e são as mesmas de antes (marca na janela, como no ao-check)
```
```gherkin
Given duas telas com a saída aberta
When uma tela é apagada no ✕ da árvore da Saída avançada
Then a janela de saída dela fecha na hora; Ctrl+Z traz a tela de volta e reabre a saída dela
```

## AC-3: O X sempre tem saída
```gherkin
Given um diálogo aberto no programa (Preferências)
When o X da janela é acionado
Then aparece um aviso dizendo para fechar o diálogo antes (em vez de nada acontecer)
```
```gherkin
Given a janela de controle sem responder (laço ocupado de 8 s iniciado pelo teste)
When o X da janela é acionado
Then em até 3 s o processo principal mostra um diálogo nativo "O OpenLuz não está respondendo: Fechar mesmo assim / Esperar"
     e registra a linha no openluz.log
```

## AC-4: Queda repetida da placa não vira abre-e-fecha sem fim
```gherkin
Given o programa aberto fora do modo de teste
When o processo de GPU é morto (taskkill no processo --type=gpu-process do programa)
Then o programa reabre e recupera, como hoje
When o processo de GPU do programa reaberto é morto de novo em menos de 60 s
Then o programa NÃO reabre outra vez: mostra um aviso nativo explicando e fecha
```

## AC-5: O editor de texto não abre duas vezes
```gherkin
Given um clipe de texto selecionado, primeira abertura do editor na sessão
When "✎ Editar texto" recebe dois cliques reais com 30 ms de intervalo
Then existe uma só janela do editor, e Esc a fecha deixando o programa acessível
```

```gherkin
     webcam-check e rosto-check ficam como na linha de base (são de outros lotes)
```
