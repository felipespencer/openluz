## AC-1: a tecla é de quem está na frente
```gherkin
Given um menu aberto (da barra ou do botão direito) e um clipe no ar
When se aperta Esc
Then o menu fecha e o clipe continua no ar
```
```gherkin
Given um diálogo aberto e um clipe selecionado fora do ar
When se aperta Enter
Then o diálogo fecha e o clipe continua fora do ar
```
```gherkin
Given a Saída avançada aberta com um slice selecionado e um clipe no ar na grade
When se aperta Delete, e depois Ctrl+N
Then só o slice é apagado; a grade e a composição ficam como estavam
```
```gherkin
Given o Automape aberto por cima da Saída avançada
When se aperta Delete, Ctrl+Z, seta e T
Then a Saída avançada não muda
```

## AC-2: os editores não descartam trabalho sem querer
```gherkin
Given a Saída avançada com mudanças
When se aperta Esc
Then aparece uma pergunta; Cancelar mantém aberta com as mudanças; OK fecha cancelando. Sem mudança, fecha direto
```
```gherkin
Given o Automape com foto carregada, fechado com Esc
When se abre de novo
Then continua no mesmo passo, com a foto e as formas
```
```gherkin
Given "criar" do Automape com a Saída avançada já aberta e com mudanças
When se dá Ctrl+Z, e depois Cancelar
Then o Ctrl+Z tira só o que o Automape criou; o Cancelar volta ao começo da sessão
```
```gherkin
Given o editor de texto com o foco num campo
When se aperta Esc
Then só sai do campo; o segundo Esc fecha o editor
```

## AC-3: nada regrediu
```gherkin
Given a rodada de baterias do 12-03
When todas rodam de novo
Then o resultado é igual (só o webcam-check reprova)
```
