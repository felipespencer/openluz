<acceptance_criteria>

## AC-1: Pixels inteiros e Ctrl
```gherkin
Given um slice ou uma máscara selecionado no modo Transformar
When arrasto o corpo, um canto ou um lado
Then a posição e o tamanho ficam em pixels inteiros; com Ctrl seguro, ficam livres (com fração) e o ímã não gruda
```

## AC-2: Shift
```gherkin
Given um item selecionado
When arrasto o corpo com Shift
Then ele só anda no eixo em que o mouse andou mais
When arrasto um canto com Shift
Then a proporção largura/altura se mantém, com o canto oposto fixo
```

## AC-3: Alt
```gherkin
Given um item selecionado
When arrasto o corpo com Alt
Then nasce uma cópia com nome novo, é ela que anda, o original fica no lugar, e um Ctrl+Z desfaz a cópia inteira
When arrasto um canto com Alt
Then o item cresce para os dois lados e o centro não sai do lugar
```

## AC-4: Anel de giro
```gherkin
Given um slice (Entrada ou Saída) ou uma máscara selecionado no modo Transformar
When arrasto o anel em volta de um canto
Then o item gira em volta do centro e o campo Giro acompanha; em máscara, os pontos giram
```

## AC-5: Roda do mouse
```gherkin
Given o palco da Saída avançada
When giro a roda do mouse sobre ele
Then o zoom muda aos poucos, o campo de zoom mostra a porcentagem, e "Ajustar" volta a encaixar
```

## AC-6: Nada quebra
```gherkin
Given as mudanças
When rodo ao-gestos-check, ao-check, ao-menu-check, ao-mesh-check, soft-check, loteb-check, o selftest e as 30 baterias
Then tudo aprovado; Ctrl+Z desfaz cada gesto num passo só; 0 CRLF novos; nada aberto
```
